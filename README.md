# Tabicuts Library 翼

A community library of projects, study notes, PDFs, Anki decks, guides, and other learning resources. Learn something, create something, and pass it on.

**Website:** https://projects.tabicuts.com — deployment is being connected; this repository is the public contribution catalogue, not the website engine.

## Contribute without touching anyone else's code

- **Simple route:** [submit a resource proposal](https://github.com/rayanwork2525-beep/tabicuts-library/issues/new?template=resource.yml). Include the resource page, creator, free download if applicable, and reuse terms. Nothing is published automatically.
- **GitHub route:** fork this repository, add an entry to `projects.json`, and open a pull request. See [CONTRIBUTING.md](CONTRIBUTING.md).
- **Fix or report:** open an issue for errors, unavailable links, attribution problems, or removal requests. Avoid posting private personal information.

You do not need access to the private Tabicuts website repository. Everyone's approved resources appear together on the library's shelves. Trusted contributors still follow the review process.

## Resource types

Projects and study tools · PDFs · Anki decks · Guides · Courses · Other learning resources.

PDFs and Anki decks currently use stable public download links. Direct website uploads and accounts are future features. Put original small files under `resources/` or larger files in this repository's Releases; do not commit executable installers or private data.

## Free learning and ownership

Creators keep ownership and receive credit. Tabicuts-authored original educational text and catalogue descriptions in this repository use **CC BY-NC-SA 4.0**, except where otherwise stated: noncommercial sharing/adaptation with credit and ShareAlike. Commercial reuse requires separate permission. Third-party resources and code retain their own explicitly stated terms; listing a resource does not relicense it. See [LICENSE.md](LICENSE.md).

An app can be free to use while its source remains private. No contributor must publish private source code to be listed. Never submit textbooks, paid decks, copied images/audio, or other material you do not have permission to share.

## Publication

A maintainer reviews proposals and catalogue changes. The private website importer then checks this repository periodically and proposes an update for owner review. After approval and deployment, the resource appears on the website. Checks are format validation, not approval of accuracy, safety, or copyright ownership. The catalogue is intentionally empty until real resources are reviewed.
